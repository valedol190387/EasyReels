# Черновик: резка + субтитры + финал

Черновик — только резка, субтитры и стандартная финальная заставка. Никакой графики, звуков, мемов, зумов: они после «ок».
Перед началом перечитай `AGENTS.md` и `profile.json` (раздел `cut`, `subs.terms`). Нет `profile.json` — сначала скилл reels-start.

## 1. Исходник

Видео — в `inbox/`. Номер NN — следующий свободный по `plans/` (01, 02…). Название — 3–5 слов по смыслу ролика.
`python3 tools/transcribe.py inbox/<видео> NN` → `work/rawNN.txt` и `work/rawNN.json`: фразы, нарезанные по настоящим паузам, каждая расшифрована отдельно — таймкоды точные.
Прочитай целиком: о чём ролик, где хук, где вода. **Дубли ищи глазами**: одинаковые начала фраз подряд или через паузу («Короче, смотрите… / Короче, смотрите, тут…») — оставляй последний полный заход.

## 2. План резки — `plans/rNN.json`

```json
{"id": "NN", "title": "…", "src": {"1": "inbox/<видео>"}, "fix": [],
 "blocks": [[1, начало, конец, "о чём блок"], …]}
```
- Границы блока — по фразам из `rawNN.json`: начало = start первой фразы, конец = end последней. Пауза между фразами > 0,7 с — разрезай на два блока.
- Резать внутри фразы (выкинуть «ну и», оборвать перед повтором): `python3 tools/transcribe.py inbox/<видео> NN --words <от> <до>` — точные слова этого куска; такой блок помечай «!» (границы как есть).
- Не верь пословным таймингам whisper по целому файлу — к концу они уезжают на секунды.
- Из дублей — последний полный заход (если в анкете `cut.takes = ask` — покажи варианты человеку).
- Выкинуть: паузы, оговорки, «так, пишет?», «стоп, ещё раз», паразиты (по анкете), оборванные мысли, воду. Длина — по смыслу (или из анкеты).
- Мат — по анкете (`keep` оставить; `cut` вырезать словом; `beep` — оставить и отметить блок для запикивания на монтаже).
- Ни один блок не начинается с тишины/вдоха: если первое слово далеко от начала блока — сдвинь начало и поставь «!» в начало заметки (границы как есть).
- Ошибки распознавания в субтитрах — пары в `"fix"`: `["^клод$", "Claude"]`.

## 3. Цикл до чистоты

1. `python3 tools/cut.py plans/rNN.json --run` → `public/sourceNN.mp4`, карта `src/data/mapNN.json`.
2. `tools/.venv/bin/python tools/gaze.py NN` → отрезки «не в камеру» + лист кадров `work/gazeNN.jpg`. **Посмотри лист глазами**: ложные срабатывания (моргнул, кивнул) отбрось. Реальные: слова не важны → вырежи из плана; важны → оставь и запиши «закрыть графикой: NN,N–NN,N с» для монтажа. Хук с нарочным взглядом в сторону — не трогать.
3. `python3 tools/dupcheck.py plans/rNN.json` → перезаходы и паузы ≥ 0,7 с. Перезаход — оставь один заход (раздели блок); пауза — разрежь блок.
4. Поправил план → снова 1–3. Пока флагов не останется (обычно 1–2 прохода).

## 4. Субтитры и черновик

1. `python3 tools/words.py plans/rNN.json` → `src/data/wordsNN.json`. Прочитай текст: ошибки → в `"fix"` плана, перезапусти.
2. `python3 tools/preview.py plans/rNN.json` → `drafts/NN — <название> (черновик).mp4`.
3. Сам проверь: кадры на 4–5 склейках (`ffmpeg -ss <время> -i <черновик> -frames:v 1 work/c1.jpg`) — нет скачка головы, обрубленного слова, тишины в начале куска; субтитры 1–2 строки и не на лице.

## 5. Отчёт человеку

Коротко: длительность; таблица блоков «время в черновике → откуда в исходнике → о чём»; что выкинул и почему (одной строкой на пункт); места «закрыть графикой». Финал сообщения:
«Смотри черновик в drafts/. Правки — по таймкодам („7–9 с вырежи“, „на 15 с верни фразу про …“). Если всё ок — пиши „ок“, перейду к графике.»

## Правки

Таймкод черновика → блок по `src/data/mapNN.json` (поле `dst`, с учётом ускорения) → поправь `plans/rNN.json` → шаги 3–4. С нуля не пересобирать.
Если правка — общее правило («всегда режь …») — допиши его в «Правила автора» в `AGENTS.md`.
