# Монтаж после черновика

Резку и субтитры черновика не трогать. Перечитай `AGENTS.md`, `profile.json` (sound, cta), отчёт черновика (места «закрыть графикой»).
Дизайн-система отвечает «как выглядит» (`src/kit`), этот скилл — «что, куда и когда».

## 1. Разбор — по `src/data/wordsNN.json`, с таймкодами

- хук — первые 3–8 с;
- места «закрыть графикой» (не в камеру) из черновика;
- названные конкретные вещи: сервис, сайт, приложение, человек, новость — нужен реальный кадр/скриншот;
- цифры, перечисления, шаги, сравнения «было/стало», команды;
- эмоции и панчлайны, где важно лицо;
- дыры: упомянул действие, но не сказал как (команду, кнопку, где найти) — допишем коротко текстом.

## 2. Раскадровка — НА СОГЛАСОВАНИЕ, до любого рендера

Таблица человеку: `таймкод — фраза — что в кадре — тип` (оверлей над головой / полноэкранная сцена / мем / скриншот / чисто).
Для мемов и скриншотов — 2–3 варианта: мемы из `public/library/catalog.json` по описанию (`what`, `tags`, `quote`); скриншоты — где взять (сделать самому или попросить у человека).
Жди «ок» или замены. Свои файлы человек кладёт в `brand/refs/` или `public/`.

## 3. Правила графики

1. Хук — лицо открыто: `Hook` (над головой). Смешные/эмоциональные моменты лица — только оверлеи сверху/сбоку.
2. Не в камеру ≥ 0,5 с — полностью закрыть полноэкранной сценой, запас 0,15 с по краям, жёсткая склейка (без проявления).
   **Исключение — указание на кадр**: если человек говорит «вот сейчас над головой», «как видите», «вот здесь» или показывает рукой —
   это не отворот, а жест. Лицо оставить, а графику поставить туда, куда он показывает: `OverHead`, несколько карточек,
   каждая — в момент своего слова («рост» → bars, «в три раза» → stat, «бот» → tag). Смысл речи важнее детектора взгляда.
3. Полноэкранные сцены обязательны (видео уходит целиком): `Counter`, `Bars`, `Quote`, `List`, `BeforeAfter`, `Terminal`, `Chat`, `Funnel`, `Chapter kind="glitch"` — каждая внутри `<Enter>`. Две подряд без лица между ними — нельзя.
4. Плотность: элемент раз в 5–10 с; реальные врезки (скрины, мемы) по конкретным словам — не реже раза в 10–12 с.
5. Смысл — движением, не текстом: не «иконка + два слова», а действие (счётчик крутится, сообщения прилетают, команда печатается). Крупных заголовков ≤ 5–6 на ролик.
6. Названа конкретная вещь — реальный скриншот (`Shot`, целиком + лупа `focus` на важном), не генерация и не стоки. Не дублировать то, что видно в записи.
7. Врезка не спорит со смыслом фразы. Сомневаешься — чисто.
8. Иконки — только из `lucide-react` / `simple-icons` / набора. Руками SVG-иконки не рисовать. Пустых плашек-заглушек не ставить.
9. Не повторять один приём подряд; в каждом ролике — своя связка.
10. Зумы `Cam zooms`: на ударных словах и смене мысли, раз в 8–12 с; `hold: true` — остаться крупно до склейки.
11. Дыры — короткой плашкой `Terminal` / `Chapter kind="terminal"`. Команды проверять.
12. Цифры о внешнем мире — правдивые; о себе автор говорит как хочет.
13. Субтитры гасить только на полноэкранных сценах с крупным текстом (`FULL`) и на финале.
14. Вход полноэкранной сцены — `<Enter>` (наезд/сдвиг за 7 кадров) при жёсткой склейке. `Transition` (whip/slide) — редко, только на смене темы. Никаких вспышек, затемнений и моргания.
15. Перечисление в речи («цены, сроки, гарантии») — не одна карточка, а по элементу на каждое слово, синхронно с речью.

## 4. Мемы и звук

- Мем: `Meme file="memes/<файл>"` — оверлей без звука (поверх головы) или `cover sound` — разрез со своим звуком (тогда голос в этот момент должен молчать: ставь мем в паузу между блоками или попроси человека). Только если реально в тему.
- В анкете `sound.memes = search` — можно искать на YouTube (`yt-dlp`): качать ролик целиком, смотреть кадры с шагом 1–4 с, выбирать момент глазами. Вслепую по таймкоду не резать.
- Звуки: `HITS` из `public/library/sfx` (каталог: категории «Пак саунд-эффектов», «Щелчки камеры», «Бульки», «Компьютерное», «Разное»), громкость 0,09–0,16, на появление элементов и удары. Если `brand.sfx = false` — без звуков.
- Музыка: только если `sound.music = baked` — `Music file="music/…"` тихо (0,07).
- Мат по анкете `beep` — `Cam bleep={[{from, to}]}` на каждое слово.

## 5. Сборка

1. `cp -r src/reels/_template src/reels/rNN`, заполни `Reel.tsx` по согласованной раскадровке (импорт `../../data/wordsNN.json`, `SRC`, `VOICE`).
2. Добавь в `src/reels/index.ts`: `import * as rNN from "./rNN/Reel";` и `rNN.entry` в `REELS`.
3. `pnpm exec tsc --noEmit`.
4. Кадр на каждом элементе: `pnpm exec remotion still ReelNN work/rNN/<t>.png --frame=<кадр>`; посмотри все. Проверь: первые 3 с лицо открыто; ничего не наезжает на лицо и субтитры; текст читается (контраст) и не обрезан; опечаток нет (выпиши весь текст на экране списком и проверь); безопасные зоны. Исправь сам.

## 6. Финал и проверка

1. `python3 tools/final.py plans/rNN.json` → `final/NN — <название> (финал).mp4`.
2. Проверка до слова «готово»:
   - кадры на всех склейках ±0,3 с — нет отворота головы, нет мычания перед словом;
   - `tools/.venv/bin/python tools/gaze.py "final/NN — ….mp4"` — все «не в камеру» ≥ 0,5 с закрыты сценами;
   - лист кадров по всему ролику раз в 2 с — читаемость, наложения, пустоты.
   Нашёл — исправь, перерендери.
3. Отчёт: таблица «таймкод → элемент → зачем» и путь к файлу.

## Запомнить

Если человек поправил монтаж словами «всегда» / «никогда» / «запомни» — допиши правило в «Правила автора» в `AGENTS.md`.
