# Старт: установка → анкета → оформление

Говори с человеком коротко и по-русски. Он не программист: не проси его запускать команды — запускай сам.

## 1. Установка (если чего-то нет)

Проверь: `models/ggml-large-v3-turbo.bin`, `node_modules/`, `tools/.venv/`, `public/library/catalog.json`.
Если хоть чего-то нет — `bash setup/install.sh` (macOS/Linux; 5–15 минут, качает ~2 ГБ: модель распознавания речи, зависимости, медиатеку).
Скажи человеку, что идёт установка и сколько примерно ждать. Если скрипт упал — прочитай ошибку, почини причину, перезапусти.
Windows: скажи, что нужен WSL (Ubuntu) — дальше всё как на Linux.

## 2. Анкета

Запусти `python3 setup/anketa/server.py` — откроется страница в браузере. Скажи человеку:
«Открыл анкету в браузере. Заполни, что знаешь, остальное оставь — там уже стоят варианты по умолчанию. Нажми „Сохранить“.»
Команда ждёт сохранения и сама завершится. Ответы — в `profile.json`, файлы — в `brand/`.
Если браузер не открылся — дай человеку ссылку из вывода команды.

## 3. Оформление

1. `python3 tools/brand.py` — анкета → `src/brand.ts`.
2. Если в `brand/design/` есть файлы (своя дизайн-система):
   - HTML из Claude Design — упакованная страница: внутри `<script type="__bundler/manifest">` (base64, часто gzip) и `<script type="__bundler/template">` (JSON-строка с разметкой). Распакуй в `work/design/` и прочитай.
   - zip — распакуй; если внутри папка `remotion/` с `tokens` — бери цвета и шрифты оттуда.
   - картинки/PDF — посмотри глазами.
   Из дизайн-системы бери ТОЛЬКО токены: 5 цветов (фон, плашки, текст, акцент, второй акцент) и шрифты. Запиши их в `profile.json → style.colors` и, если шрифт не из списка, добавь загрузчик в `LOADERS` в `src/kit/tokens.ts` (через `@remotion/google-fonts/<Имя>`) и пропиши его в `src/brand.ts` через `profile.json → style.fonts`. Перезапусти `tools/brand.py`.
   Компоненты `src/kit/*.tsx` не переписывай — они отлажены. Новое оформление = новые токены.
3. Проверка: `pnpm exec tsc --noEmit`, затем 4 кадра набора:
   `pnpm exec remotion still KitPreview work/kit/hook.png --frame=40`, `--frame=110` (плашка), `--frame=790` (кодовое слово), `--frame=1640` (финал).
   Посмотри картинки: текст читается (контраст), ничего не обрезано, ник и аватар на месте. Исправь, если не так.

## 4. Финал шага

Коротко покажи человеку, что настроено (ник, куда ведём, стиль, субтитры, музыка), и скажи:
«Готово. Кидай сырое видео в папку inbox и пиши „черновик“.»
