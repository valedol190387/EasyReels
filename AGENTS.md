# AGENTS.md — монтаж вертикальных роликов

Проект монтирует говорящую голову в Reels/Shorts: резка по словам, субтитры, графика из набора, финал.
Работает в любом агенте (Codex, Claude Code, Cursor). Человек не пишет промпты — он говорит фразы ниже.

## Фразы человека → что делать

| Говорит | Делай |
|---|---|
| «начни», «настрой», первый запуск | скилл **reels-start**: установка → анкета → оформление |
| «черновик», кинул видео в `inbox/` | скилл **reels-draft**: резка + субтитры + финал → `drafts/` |
| правки по таймкодам черновика | правь план `plans/rNN.json`, пересобери черновик (reels-draft, раздел «Правки») |
| «ок», «черновик ок», «монтируй» | скилл **reels-montage**: раскадровка → графика → финал → `final/` |
| «анкета», «поменяй ник/цвета» | `python3 setup/anketa/server.py`, потом `python3 tools/brand.py` |
| «запомни …», «всегда / никогда …» | допиши правило в раздел «Правила автора» в конце этого файла |

Скиллы лежат в `.agents/skills/` (Codex) и `.claude/skills/` (Claude Code) — одинаковые. Если агент не видит скиллов — открой `.agents/skills/<имя>/SKILL.md` и выполняй по нему.

## Где что

- `profile.json` — ответы анкеты (ник, ссылки, резка, субтитры, звук, стиль, призыв). Читай перед каждой задачей.
- `src/brand.ts` — оформление из анкеты (генерирует `tools/brand.py`). Руками не править.
- `src/kit/` — набор графики (стиль «Кухня Технаря · Video Kit v2»). Новое оформление — только через токены `src/kit/tokens.ts`, компоненты не переписывать.
- `tools/` — инструменты (Python): `transcribe`, `cut`, `gaze`, `dupcheck`, `words`, `preview`, `final`, `library`, `brand`. `gaze.py` — через `tools/.venv/bin/python`, остальные — `python3`.
- `inbox/` — сырые видео. `plans/rNN.json` — план резки. `drafts/` — черновики. `final/` — готовые ролики.
- `public/library/` — медиатека: `sfx/`, `memes/`, `music/` + `catalog.json` (что в каждом файле).
- `src/reels/rNN/Reel.tsx` — монтаж ролика NN; реестр — `src/reels/index.ts`.

Номер ролика NN — две цифры по порядку (01, 02…), смотри существующие `plans/`.

## Главные правила

**Порядок неизменен:** черновик (резка + субтитры + финальная заставка) → правки → «ок» → графика, звуки, мемы, зумы → финал. Графику на неутверждённую резку не вешать.

**Резка**
- Резать только по концам слов (пословные тайминги + прилипание к тишине в `cut.py`). Слово пополам — брак.
- Ни один блок не начинается с тишины или вдоха — иначе заметка «!» и точные границы.
- Дубли: оставлять последний полный заход (или как в анкете). Whisper склеивает «заход + перезаход» — поэтому `dupcheck.py`.
- Ускорение, паузы, паразиты, мат, отступления, длина — из `profile.json → cut`. Длина по умолчанию — по смыслу: режем воду, а не мысли.
- Не в камеру (`gaze.py`, лист кадров смотреть глазами): слова не важны → вырезать; важны → оставить и закрыть полноэкранной сценой на монтаже.

**Картинка**
- Хук (первые 2–3 с) и эмоциональные моменты лица — лицо не закрывать: графика сверху/сбоку.
- Человек показывает на кадр («вот над головой», «как видите», жест рукой) — графика появляется там, куда он показывает, по словам; лицо не закрывать, даже если детектор взгляда ругается.
- Переходы без вспышек и моргания: жёсткая склейка + сцена въезжает сама (`Enter`).
- Безопасные зоны 1080×1920: сверху 230, снизу 420, справа 175, по бокам 110 px; панели не шире 860 px.
- Субтитры: низ текста на 380 px от низа, 1–2 строки, группы до 24 символов, на лице никогда.
- Текст на плашке всегда контрастный (`textOn()` в токенах). Тёмный на тёмном — брак. Весь текст на экране проверять на опечатки.
- Цифры и факты о внешнем мире — только правдивые. Команды и названия — проверять, не выдумывать.

**Звук**: громкость готового ролика −14 LUFS; звуки эффектов тихие (0,09–0,16); музыка — только как выбрано в анкете (чужой трек могут заглушить).

**Сдача**: финал — мастер из рендера, второй проход «чтобы легче» не делать. Перед словом «готово» — проверка финала (reels-montage, шаг 6).
